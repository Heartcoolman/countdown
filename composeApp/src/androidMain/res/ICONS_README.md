## 图标设计建议

- 主色调：#2196F3 (蓝色)
- 图标应包含时钟或倒计时相关的视觉元素
- 保持简洁和现代的设计风格
- 确保在深色和浅色背景下都清晰可见

## 临时方案

在开发阶段，可以使用以下工具快速生成图标：
- Android Asset Studio: https://romannurik.github.io/AndroidAssetStudio/
- Icon Kitchen: https://icon.kitchen/
